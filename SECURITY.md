# Security

## Reporting Issues

If you find a security or safety issue, please avoid posting exploit details publicly before it can be reviewed.

For a private repository, contact the repository owner directly. If this repository is public and GitHub private vulnerability reporting is enabled, use that feature.

## Scope

Relevant issues include:

- Bluetooth behavior that could move the desk unexpectedly.
- UI behavior that hides or blocks stop/disconnect controls.
- Cross-site scripting or unsafe dependency behavior.
- Documentation that could cause unsafe setup or use.

## Safety

This app controls physical desk movement. Keep the desk in sight while testing, keep the area clear, and be ready to use the physical desk controls or disconnect power if needed.
